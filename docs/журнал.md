# Журнал работ

## Шаг 1. Каркас

11 октября 2026

Появился каркас сервиса. База данных ещё не подключается.

- Пакеты `app.api`, `app.calendar`, `app.db` и пустой `app.assistant`.
- Имя приложения читается из окружения `APP_NAME`. Если переменная не задана, используется «Arachis Assistant».
- `GET /api/v1/health` отвечает `{"status": "ok"}` без авторизации.

Проверка из корня репозитория:

```bash
uv sync
uv run pytest
uv run uvicorn app.main:app --reload
```

После запуска открыть http://127.0.0.1:8000/api/v1/health

Интерпретатор проекта — Python 3.15.

## Шаг 2. PostgreSQL

11 октября 2026

Сервис подключается к PostgreSQL. Таблиц календаря ещё нет: первая миграция пустая и только создаёт служебную таблицу Alembic.

- База и API поднимаются вместе: `docker compose up --build`.
- Адрес базы с хоста: `postgresql+psycopg://arachis:arachis@localhost:5432/arachis`. В контейнере API он задаётся переменной `DATABASE_URL`.
- При старте приложение проверяет соединение. Если база недоступна, процесс не начинает принимать запросы.
- `GET /api/v1/health` по-прежнему отвечает `{"status": "ok"}`.

Проверка:

```bash
docker compose up --build -d
uv run alembic upgrade head
uv run pytest
```

После запуска открыть http://127.0.0.1:8000/api/v1/health
