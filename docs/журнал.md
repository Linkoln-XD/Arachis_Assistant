11 октября 2026

Сервис подключается к PostgreSQL. Таблиц календаря ещё нет: первая миграция пустая и только создаёт служебную таблицу Alembic.

- База и API поднимаются вместе: `docker compose up --build`.

Проверка:

```bash

uv run alembic upgrade head
uv run pytest
```

После запуска открыть http://127.0.0.1:8000/api/v1/health

## Шаг 3. Регистрация

11 октября 2026

Появилась регистрация. Вход, обновление токена и профиль будут следующим шагом.

- `POST /api/v1/auth/register` создаёт пользователя и сразу возвращает сессию: access token на 15 минут и refresh token на 30 суток.
- Почта обрезается и приводится к нижнему регистру. Повторная почта отвечает `409 email_taken`.
- Пароль хранится только как хэш. Пробелы по краям пароля сохраняются.
- Часовой пояс по умолчанию — `Europe/Moscow`. Неизвестный пояс отвечает `422 validation_error` с кодом поля `invalid_timezone`.
- Секрет подписи токена читается из `JWT_SECRET`. Локальное значение по умолчанию подходит для разработки.

Проверка:

```bash
docker compose up --build -d
uv run alembic upgrade head
uv run pytest
```

Пример запроса:

```bash
curl -s -X POST http://127.0.0.1:8000/api/v1/auth/register \
  -H 'Content-Type: application/json' \
  -d '{"email":"user@example.com","password":"password1"}'
```

## Шаг 4. Сессия

11 октября 2026

Появились вход, обновление токена, выход и профиль.

- `POST /api/v1/auth/login` возвращает новую сессию. Неизвестная почта и неверный пароль отвечают одинаково: `401 invalid_credentials`.
- Больше 10 попыток входа в минуту с одного адреса отвечает `429 too_many_requests`.
- `POST /api/v1/auth/refresh` выдаёт новую пару токенов. Прежний refresh token после этого не действует. Просроченный и неизвестный отвечают `401 invalid_refresh`.
- `POST /api/v1/auth/logout` отзывает refresh token и отвечает `204`. Повторный выход тоже отвечает `204`. Уже выданный access token действует до своего срока.
- `GET /api/v1/auth/me` и `PATCH /api/v1/auth/me` требуют access token. Просроченный токен отвечает `401 token_expired`, отсутствующий или испорченный — `401 unauthorized`.
- Смена пояса меняет только отображение времени. Сохранённый момент создания пользователя остаётся тем же.

Проверка:

```bash
uv run pytest
```
